# 對客戶展示：晴川系統整合

開發機與展示機的 Seeder 會建立一家虛構的系統整合商「晴川系統整合股份有限公司」（slug `showcase`），用來對客戶示範系統。資料由 [ShowcaseSeeder](../apps/api/QuotePlatform.Api/Infrastructure/ShowcaseSeeder.cs) 產生，所有日期都從**執行當天往回推算**，所以每次重置後，Dashboard 的今年、去年同期、逾期應收與到期保固都是「現在」的樣子。

公司、客戶、人名與聯絡方式都是虛構的；Email 一律用 `.example` 網域，沒有填統一編號，避免碰巧對到真實公司。

## 重置

```bash
npm run demo:reset
```

這個指令會：

1. 刪除**所有**公司與它們的資料，以及不屬於平台的帳號。只保留權限目錄、系統角色和 `admin`。
2. 由 Seeder 重建 smoke 測試用的 `demo` 公司（只有帳號與部門），以及這家展示公司。

- 只能在 `Quote__SeedDemoData=true` 的環境執行，正式環境不會開這個旗標。
- 執行前請先備份，例如 `mariadb-dump quote_platform > backups/…`；`backups/` 已列入 `.gitignore`。
- file-server 上的檔案本體不在資料庫裡，要另外清除：開發機刪掉 `file-server/data/objects/` 底下不存在的公司 ID 目錄。
- 什麼時候用：smoke 測試會在 demo 公司與它自己建立的公司裡留下大量資料，跑完測試、或要對客戶展示之前，各執行一次。

## 資料內容

- 組織：總經理 → 業務部（業務一課、業務二課）、工程部、財務部。
- 品項價目 12 項：網路設備、資安、伺服器、儲存、監控、施工、服務、維護。
- 客戶 8 家（製造、生技、物流、醫療、營建、旅宿、會計師事務所、大學），都有簡稱和聯絡人。
- 專案 18 個，跨去年與今年，每一種狀態都有：

| 狀態 | 數量 | 代表案例 |
|---|---|---|
| 草稿 | 1 | 新竹分所開設：還沒報價，只有拜訪紀錄 |
| 報價中 | 3 | 宿舍網路升級（**待核准**）、研發大樓網路規劃（已送出，**下次聯絡已逾期**）、新建案工地網路（草稿報價） |
| 得標 | 2 | 急診資訊機房擴充（本月成交）、會議室影音與網路 |

| 已完工 | 4 | 圖書館無線網路（三年保固）等 |
| 已結案 | 4 | 去年的案子，提供 Dashboard 的去年同期 |
| 未得標 | 1 | 停車場監控：客戶拒絕報價，原因「預算刪減」 |
| 已取消 | 1 | 舊廠機房搬遷 |

**旗艦專案「二廠新廠區網路建置」**是整條流程的範例：

- 成員：負責人、管理成員和檢視成員。
- 報價：R0 原價送出，議價後改版為 R1（95 折，付款改三期），R0 標示為已被取代。
- 訂單：客戶接受 R1 後成立。
- 出貨：分兩批，已簽收與已出貨各一批。
- 發票：訂金已收、第一批款項未到期、驗收款尚未開立。
- 保固：有一張保固單。
- 跟進：5 筆紀錄，包含主管陪同議價那一筆。

Dashboard 會呈現：
- 今年對比去年同期的成長。
- 成交率。
- 業務排行。
- 1 張逾期應收。
- 3 張 90 天內到期的保固，其中 1 張幾天後到期。

## 建議的展示流程（約 15 分鐘）

1. **老闆視角（`sc-ceo`）**：先看首頁 Dashboard。
   - 今年的報價接受和去年同期相比成長多少。
   - 切換報價接受、接單、開票三種口徑。
   - 點開逾期應收與到期保固。
2. **客戶管理**：客戶列表用簡稱搜尋（例如「瑞峰」）。打開一家客戶，看聯絡人與所屬部門。
3. **旗艦專案**：從專案列表點開「二廠新廠區網路建置」，依序看各頁籤。
   - 報價：R0 → R1 的改版紀錄。
   - 訂單、出貨（分批）、發票（分期收款）、保固。
   - 跟進紀錄：下次聯絡與要做的事。
   - 附件：現場拖一個 PDF 上傳，示範附件功能。
4. **現場開一張報價**（`sc-kevin`）：打開「新建案工地網路」的草稿報價。
   - 從品項價目帶入品項，加一個整單折扣，看後端算出的稅額與總計。
   - 按「送審」，再下載 PDF 給客戶看格式。
5. **主管核准**（`sc-manager`）：打開「宿舍網路升級」的待核准報價，按「核准」。
   - 說明已送出的報價不能修改，只能改版。
6. **權限與資料範圍**：
   - 換成 `sc-amy`：只看得到自己的 5 個專案，選單沒有公司設定。
   - 直接開陳大文的專案網址，會顯示「找不到專案」。
   - 換成 `sc-finance`：開「台南轉運站監控」的逾期發票，示範登記收款。
   - 換成 `sc-engineer`：看到旗艦專案，但只能檢視。
7. **跟進總表**（`sc-manager`）：看兩個課所有業務的跟進，紅字是逾期未聯絡的。
8. **加分項**：虛擬辦公室；用 `admin` 看平台的多公司管理。

展示中改過的資料，結束後執行 `npm run demo:reset` 就會回到原樣。
